# Kairn 0.8.3

Same key as 0.8.2, so this installs straight over it - your books, places, notes and settings stay put.

**Reading aloud with the screen off.** Lock the phone and Kairn keeps reading. A media-playback service holds
the session alive and the notification has a Stop button.

**Continue reading** shows one progress bar, inside the cover, and under the title how far you are and when you
were last in that book ("42% - 3d ago").

**Automatic backup.** Choose a folder in Settings once. Every few days a backup zip goes there on its own and
the newest few are kept. Only Kairn's own files are ever touched.

**Search cache.** The first text search in a book reads it once and stores its text; later searches answer from
that cache. Settings shows how much space it uses and clears it.

**Lighter on open.** The device-wide scan runs once a day instead of every time the library opens. "Find books
on this device" still runs it immediately.

Built against Android 16 (SDK 36), with current AndroidX libraries.
